Objectif : Ce guide vous accompagne pas à pas dans la création d'un rapport de formation au format PDF sur la plateforme Neemba Academy. Vous y trouverez la description de la navigation, le détail des 11 sections du formulaire, les formats de fichiers acceptés et les bonnes pratiques.

home Découvrir l'application

L'application est organisée autour de 3 espaces accessibles depuis la barre de navigation en haut de page :

home
Accueil
Page d'introduction qui présente la plateforme Neemba Academy et les modules à venir (Formations, Budgets, Référentiels, Import / Export, Administration). Lors de votre première visite, une courte animation d'introduction (~4 s) est jouée — vous pouvez l'ignorer avec le bouton Skip ou la touche Esc.
description
Rapport — c'est ici que vous générez vos rapports.
Formulaire en 11 étapes pour saisir toutes les informations d'une formation, prévisualiser le rendu, puis exporter en PDF. Le PDF est généré nativement avec ReportLab.
dashboard
Tableaux de bord
Dashboard Power BI embarqué qui consolide les indicateurs (formations, stagiaires, taux de réussite). Lecture seule.
Bon à savoir :
  • L'application ne stocke pas vos données dans une base : tout reste en mémoire et dans des fichiers temporaires de session.
  • Les uploads (logos, photos, Excel) sont conservés le temps de la session puis nettoyés automatiquement.
  • L'interface est responsive — elle s'adapte à mobile, tablette et desktop.

rocket_launch Démarrage rapide (4 étapes)

1
Ouvrez l'onglet Rapport
Dans la barre de navigation en haut, cliquez sur Rapport (ou rendez-vous directement à l'URL /rapport).
2
Saisissez l'intitulé de la formation
En haut de la page, renseignez le titre (ex : « Formation sur l'utilisation de la machine 320GC »).
3
Remplissez les 11 sections
Cliquez sur chaque accordéon pour le déplier. Vous pouvez les remplir dans l'ordre que vous voulez, mais l'ordre proposé reflète celui du PDF final.
4
Générez votre rapport PDF
Cliquez sur le bouton jaune « Générer le rapport PDF ». Une animation de génération mécanique s'affiche pendant la création du fichier (quelques secondes), puis le PDF se télécharge automatiquement.

description Guide détaillé par section

1. Informations Client

Logo : Uploadez le logo de l'entreprise cliente (formats acceptés : JPG, PNG, SVG)
Nom : Nom de l'entreprise
Téléphone : Numéro de contact
Pays : Pays de l'entreprise
Adresse : Adresse complète

2. Informations Machine

Photo de la machine : Image de l'équipement formé
Nom : Désignation de la machine
Modèle : Référence du modèle
Type : Type d'équipement
Numéro de série : Série de la machine

3. Informations Formateur

Photo : Photo du formateur
Nom & Prénoms : Identité complète du formateur
Contacts : Téléphone et/ou email
Lieu : Lieu de la formation
Nombre de participants : Nombre de stagiaires
Période : Dates de début et fin de formation

4. Sommaire

Points du sommaire : Ajoutez les différents chapitres de votre rapport
Astuce : Cliquez sur "+" après avoir saisi chaque point

5. Objectifs

Objectifs de la formation : Définissez les objectifs pédagogiques
Format : Utilisez des phrases courtes et précises

6. Contenu & Planning

Tâche : Description de l'activité
Début/Fin : Dates de réalisation
Notes : Commentaires complémentaires
Astuce : Ajoutez autant de tâches que nécessaire

7. Évaluation & Analyse

Fichier Excel/CSV : Uploadez vos données de tests
Colonnes attendues : Stagiaire | Test_In | Test_Out
Important : Le système analysera automatiquement les performances
Attention — structure du fichier : les colonnes attendues sont Stagiaire, Test_In, Test_Out. Si elles ne correspondent pas, un message d'avertissement s'affiche dans l'aperçu et les graphiques de progression peuvent être faussés. Vérifiez aussi que les valeurs de tests sont bien numériques (sans pourcentage % ni texte).

8. Médiathèque

Photos de la formation : Uploadez plusieurs images
Astuce : Vous pouvez glisser-déposer les images pour les réorganiser

9. Appréciation Formateur

Évaluez différents aspects de la formation :
• Accueil
• Logement
• Moyens mis à disposition

10. Conclusion

Conclusion de la formation : Rédigez un bilan complet
Conseil : Incluez les points clés, recommandations et perspectives d'avenir

11. Émargements

Images des émargements : Uploadez les feuilles d'émargement
Format : Images claires et lisibles

check_circle Conseils et bonnes pratiques

Bonnes pratiques :
  • Préparez tous vos fichiers (logos, photos, Excel, émargements) avant de commencer la saisie.
  • Utilisez des images de bonne qualité (idéalement ≥ 1200 px de large pour les photos de machine et de salle).
  • Nommez vos fichiers de façon explicite (logo-client.png, machine-320GC.jpg, etc.).
  • Renseignez d'abord les sections Client et Formateur — elles alimentent la page de garde du PDF.
  • Utilisez « Aperçu » pour relire le rendu HTML avant de lancer la génération PDF.
  • Sur mobile, faites pivoter votre appareil en mode paysage pour les sections avec plusieurs colonnes.
À éviter :
  • Fichiers Excel avec des colonnes renommées ou des cellules fusionnées dans la zone de données.
  • Images floues, captures d'écran de basse résolution ou photos sous-exposées.
  • Champs obligatoires laissés vides (intitulé de formation, dates, nombre de stagiaires…).
  • Fermer l'onglet en plein milieu d'une saisie — les données sont en mémoire, elles seront perdues.
  • Uploader plusieurs dizaines de photos non recadrées (privilégiez 5 à 15 photos représentatives).

restart_alt Résolution de problèmes

Problèmes courants et solutions :

Erreur d'upload
  • Vérifiez la taille du fichier (max 50 Mo pour Excel, 10 Mo pour les images).
  • Assurez-vous que le format est supporté (JPG, PNG, SVG, XLSX, XLS, CSV).
  • Vérifiez que votre connexion réseau est stable.
  • Si vous êtes derrière un VPN d'entreprise, essayez de désactiver temporairement le proxy.
Analyse Excel échouée
  • Les colonnes doivent s'appeler exactement Stagiaire, Test_In, Test_Out (sensible à la casse).
  • Les notes doivent être des nombres (pas de texte, pas de signe %).
  • Évitez les cellules fusionnées et les en-têtes multi-lignes.
  • Si vous utilisez un CSV, le séparateur doit être ; ou , (point-virgule recommandé).
Images non affichées dans l'aperçu
  • Vérifiez le format (JPG, PNG, SVG uniquement — pas de HEIC ni de WebP).
  • Assurez-vous que l'image n'est pas corrompue (essayez de l'ouvrir avec une visionneuse).
  • Si l'image dépasse 10 Mo, réduisez sa résolution avant l'upload.
PDF non généré ou bouton bloqué
  • Vérifiez que tous les champs obligatoires sont remplis (sinon le serveur renvoie une erreur 422).
  • Patientez quelques secondes — la génération peut prendre 5 à 15 s selon le volume d'images. L'animation mécanique vous tient au courant.
  • Vérifiez que votre navigateur autorise les téléchargements (un bandeau peut apparaître la première fois).
  • Désactivez les bloqueurs de pop-up et les extensions de sécurité agressives sur cette URL.
Icônes affichées comme du texte (menu_book, home…)
  • La police d'icônes Material Symbols n'a pas pu se charger.
  • Faites Ctrl+F5 pour vider le cache et recharger.
  • Si le problème persiste, contactez votre administrateur (la police est servie en local sous app/static/fonts/).
Mise en page cassée après une mise à jour
  • Forcez le rechargement avec Ctrl+F5 — le navigateur peut conserver une ancienne feuille de styles en cache.
  • En mode privé / navigation privée, le cache est isolé : c'est un bon test rapide.
